# TSCP Benchmarking

Use this skill when a TSCP planning cycle requires a monthly or on-demand external benchmark refresh.

Read `AGENTS.md`, `config/benchmark-sources.json`, and `contracts/benchmark-input.schema.json`. Inspect enabled public sources and record only verifiable observations. Return English JSON matching the benchmark contract. Separate observed facts from interpretation, use qualitative signals when metrics are unavailable, and assign confidence to trend summaries. Do not invent metrics, URLs, dates, or organization facts. Do not create a calendar; pass evidence to the strategy step.
