# TSCP Strategy

Use this skill after benchmarking when planning a TSCP monthly calendar.

Read `AGENTS.md`, `config/tscp.json`, the benchmark input, and `contracts/content-calendar.schema.json`. Meet the configured weekly floor, distribute slots across enabled campaigns, use compatible enabled platforms and formats, and preserve benchmark references. Dates are suggestions unless the user supplies fixed dates. Return English JSON for strategy slots; leave detailed ideas, CTAs, and format skeletons to the creative step.
